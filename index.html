Aide — méthode API et seuils par discipline

La méthode API évalue trois critères indépendants. Un seul critère validé peut suffire à justifier le désherbage selon le contexte.

A — Abîmé

État physique : reliure cassée, pages déchirées, taches, moisissures, annotations intrusives. À évaluer manuellement en main.

P — Périmé

Score calculé en croisant l'âge du document avec sa discipline (cote Dewey). Les seuils varient fortement selon le domaine :

I — Inadéquat

Basé sur les prêts : 0 prêt toutes périodes = score 3 · 0 prêt depuis Alma avec peu de prêts historiques = score 2 · 0 prêt depuis Alma avec usage historique = score 1 · prêts récents = score 0.

Valeur patrimoniale

Signaux détectés automatiquement (lien INSA Toulouse, éditeur confidentiel, rareté Archires). Le SUDOC est le critère décisif : moins de 15 exemplaires = fort signal patrimonial, plus de 30 = désherbage probable même si les critères API sont activés.

Score

0 = critère non rempli (vert) · 1 = possiblement (jaune) · 2 = probablement (orange) · 3 = très probablement (rouge)
